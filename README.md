# Dictionary App

A modern and responsive Dictionary App built using **HTML**, **CSS**, **JavaScript**, and **Axios**. The application allows users to search for the meaning of any English word in real time using the **Free Dictionary API**. It features a clean user interface, instant search functionality, error handling, and keyboard support for a smooth user experience.

## Features

* Search for English word definitions
* Fetches live data using the Free Dictionary API
* Displays multiple definitions of a word
* Handles invalid or unavailable words gracefully
* Search using both the **Search** button and the **Enter** key
* Responsive and modern user interface
* Clean and organized code structure

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Axios
* Free Dictionary API

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser, or run it using **Live Server** in Visual Studio Code.
4. Type an English word in the search box.
5. Press **Enter** or click the **Search** button.
6. View the definitions returned by the API.
